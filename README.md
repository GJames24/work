# Work in progress: five case studies

I build software with AI agents in the evenings, and I treat it as a product practice: measured cost, sealed evals, decision records, and regression checks born from real failures. The repositories themselves are private; this repo is their public record. Curated public editions of parts of this work are planned, and [planmeter](https://github.com/GJames24/planmeter) is the first.

| Project | One line | Page |
|---|---|---|
| **Tilda** | An agentic world simulation run like a scientific instrument: one canon thread of 74 days and simulated days reaching day 102 across its [experimental arms](glossary.md#the-trunk-an-arm), cost on every model call, a 673-check regression bench gating commits, and a weekly gathering the residents founded themselves | [tilda.md](tilda.md) |
| **The Second Stamp** | Fine-tuning an open model to fill one of Tilda's seats: hand-authored sealed eval, hash-approved GPU runs, baseline-first evaluation | [the-second-stamp.md](the-second-stamp.md) |
| **The Kitten Breeder** | The operating model extracted from Tilda: 27 chapters, most a rule paid for by a named failure, plus a starter kit for new projects | [the-kitten-breeder.md](the-kitten-breeder.md) |
| **The Cat Show** | A model benchmark built on Tilda. Frontier models are entered into the jobs the simulation's work demands (reading a day's tape, refuting a claim, [refereeing blind](glossary.md#a-referee), building to a spec), judged against written standards with every verdict traced to a trial folder, and awarded per class. First show: Opus 5 against Opus 5.5. In progress. | [the-cat-show.md](the-cat-show.md) |
| **The Verifier** | A verification pipeline for research produced largely by AI agents, aimed at open problems: a blind referee from another model family, frozen captures replayed byte for byte, and a main branch that, since the evening of October 19, has changed only by pull request under a ruleset that requires a passing check. No result on any open problem is claimed. | [the-verifier.md](the-verifier.md) |

**Field notes** ([field-notes/](field-notes/README.md)): shorter pieces from inside Tilda, each a product decision, a provenance story or an engineering postmortem with its receipts. The first three: a line in every home, Ada and the Quarto, the mail carriers.

The projects use their own vocabulary. The [glossary](glossary.md) maps it to industry terms.

**Something you can run:** [planmeter](https://github.com/GJames24/planmeter), a small tool extracted from Tilda that tracks subscription-plan usage and projects which allowance runs out first.
